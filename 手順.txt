ドライブ整理ツール 手順書
==========================================

■ 何をするツールか
  Google ドライブ内の「同じ名前のスプレッドシートが何個もある」状態を、
  最新の1件だけ残して片付けます。
  いきなり消しません。まず一覧を作り、あなたが承認した分だけゴミ箱へ移します。


■ 準備（初回だけ・5分）
  1. https://script.google.com/home を開く（art-times@smilesbase.com でログイン）
  2. 左上「新しいプロジェクト」をクリック
  3. 出てきた コード.gs の中身を全部消す
  4. C:\Users\OWNER\ドライブ整理\ドライブ整理.gs の中身を全部コピーして貼り付け
  5. 左上のプロジェクト名を「ドライブ整理」に変更して保存（Ctrl+S）


■ STEP 1：重複の一覧を作る（何も消えません）
  1. 画面上部の関数選択で「STEP1_棚卸しレポート作成」を選ぶ
  2. 「実行」をクリック
  3. 初回は権限の確認が出ます
       → 「権限を確認」→ アカウント選択 → 「詳細」→「ドライブ整理（安全でないページ）に移動」→「許可」
  4. 1〜3分待つ（ファイル数が多いと時間がかかります）
  5. 完了後、実行ログに出るURL、または
     マイドライブ →「_ドライブ整理」フォルダ の中の
     「ドライブ整理レポート_日付」を開く


■ STEP 2：一覧を見て、消すものを決める
  「重複一覧」シートを開きます。

   グループ A-◯ … 名前が完全に同じ重複。
                    一番新しい1件が緑色で「★最新（残す）」。
                    それ以外は「削除する」に自動でチェック済み。

   グループ B-◯ … 末尾の日付だけ違うもの
                    （例：仮払_売掛_点検リスト_20260714 と _20260720）。
                    別の日の作業記録かもしれないので、チェックは付けていません。
                    消していいものだけ、自分でチェックを付けてください。

  ・残したいもの → チェックを外す
  ・消したいもの → チェックを付ける
  中身が不安なときは「リンク」列から実物を開いて確認できます。


■ STEP 3：ゴミ箱へ移す
  1. スクリプトエディタに戻る
  2. 関数選択で「STEP2_チェックした行をゴミ箱へ」を選んで「実行」
  3. 終わると、一覧の該当行に取り消し線が入り「ゴミ箱へ移動済 日時」と表示されます

  ※「削除」ではなく「ゴミ箱へ移動」です。30日以内ならドライブのゴミ箱から戻せます。
  ※ まとめて戻したいときは「STEP3_ゴミ箱から戻す」を実行してください。


■ 設定の変更（ファイル冒頭の CONFIG）
  対象_スプレッドシート : true  … Google スプレッドシート（既定でON）
  対象_Excelファイル     : false … .xlsx も対象にしたいとき true に
  対象_ドキュメント      : false … 引継ぎ資料.md などの Google ドキュメントも対象にするとき true に
  自分の所有ファイルのみ : true  … 他人から共有されたファイルは触らない（ONのままを推奨）

  ※「ガソリン出納帳」など他の方が所有するファイルは、この設定により対象外です。


■ 注意
  ・GASの1回の実行は最大6分です。時間切れの場合は途中まででレポートが作られ、
    ログに「時間切れ」と出ます。その場合はもう一度 STEP1 を実行してください。
  ・下記のように、業務で常用しているファイルは重複扱いになりません（名前が一意のため）。
      飲料納価・売価一覧 / 日計・月間収支報告 / 請求額・入金額確認表 /
      手数料明細送付先一覧 / GH食材費・日用品費計算表
