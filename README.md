# ドライブ整理ツール（GAS）

Google ドライブに溜まったファイルを、**承認制**で片付ける Apps Script 一式。
会計整理の作業で増えたスプレッドシートや、売上伝票の xlsx を対象にしています。

いきなり削除しません。必ず「一覧を作る → チェックを確認する → ゴミ箱へ移す」の順で動きます。
削除ではなくゴミ箱への移動なので、30 日以内なら元に戻せます。

## 構成

| ファイル | 役割 |
|---|---|
| `ドライブ整理.gs` | 共通処理＋重複スプレッドシートの整理（STEP1〜STEP3） |
| `売上伝票.gs` | 売上伝票 xlsx の ZIP 一括ダウンロード＋重複整理（A1〜A3） |
| `作業ファイル.gs` | 会計整理で作った使い捨てシートの片付け（B1） |
| `手順.txt` | 重複整理の手順書 |
| `手順_売上伝票.txt` | 売上伝票まわりの手順書 |
| `手順_作業ファイル.txt` | 作業ファイル片付けの手順書 |

3 つの `.gs` は**同じ Apps Script プロジェクトに入れてください**。
`STEP2` / `STEP3` とレポート生成を共通で使っています。

## 使い方

[script.google.com](https://script.google.com/home) で新規プロジェクトを作り、
`.gs` の中身を貼り付けて保存。あとは目的に応じて関数を実行します。

### 重複スプレッドシートを片付ける
```
STEP1_棚卸しレポート作成()      → 一覧ができる（何も消えない）
STEP2_チェックした行をゴミ箱へ() → 承認した分だけゴミ箱へ
STEP3_ゴミ箱から戻す()          → 取り消し
```

### 売上伝票を PC に一括ダウンロードする
```
A1_対象を数える()       → 件数・容量・重複数を確認するだけ
A2_ZIPにまとめる()      → 年ごとの ZIP を作る → ドライブから 1 回で落とす
A3_重複だけ一覧にする() → 重複分の一覧 → STEP2 で削除
```

### 会計整理の使い捨てシートを片付ける
```
B1_作業ファイルを一覧にする() → 使い捨て/要確認/常用 に仕分け → STEP2 で削除
```

## 判定の考え方

- **重複**（`ドライブ整理.gs` / `売上伝票.gs`）
  名前が一致するものは、更新日が最新の 1 件を残して他をチェック。
  `のコピー` `【バックアップ】` `「〜 - 5月25日、17:54」のコピー` といった表記のゆれは吸収します。
  末尾の日付だけが違うものは別グループにして、自動チェックはしません。

- **使い捨てかどうか**（`作業ファイル.gs`）
  日付付きの名前（`_20260720` など）と作業用の言葉（点検・検証・修正リスト等）の
  両方に当てはまるものだけ自動チェック。判定語は `作業ワード` / `保護ワード` で調整できます。

## 消さないもの

- **売上伝票そのもの**（各事業所・各月 1 本）… 帳簿書類で 7 年保存が要るため、重複分しか触りません
- **MF 取込用ファイル**… どの仕訳を取り込んだかの記録になるため、自動チェックの対象外
- **引継ぎ資料**… 同上
- **他人が所有するファイル**… 既定で対象外（`自分の所有ファイルのみ: true`）
- **Google フォーム**… 対象外
