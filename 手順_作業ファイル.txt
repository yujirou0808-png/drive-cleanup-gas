作業ファイル片付け 手順書
==========================================

■ これは何か
  会計整理のときに作った使い捨てのシート
  （売掛金_整合性検証_20260720、ショート_消込漏れ_20260720 など）を片付けます。

  これらは重複していないので、「重複を消す」ツールでは1本も引っかかりません。
  そこで「日付付きの名前かどうか」「作業用の言葉が入っているか」で仕分けます。


■ 準備
  「ドライブ整理」の Apps Script プロジェクトで
  ファイル ＋ →「スクリプト」→ 名前を「作業ファイル」にして、
  C:\Users\OWNER\ドライブ整理\作業ファイル.gs の中身を貼り付けて保存。


■ 手順
  1. 関数「B1_作業ファイルを一覧にする」を実行（何も消えません）
  2. マイドライブ →「_ドライブ整理」の「ドライブ整理レポート_日付」を開く
  3. 3つに仕分けられています

     C-使い捨て … チェック済み。消してよいと判断したもの。
                   例）売掛金_整合性検証_20260720
                       今期_売掛整合性_修正リスト_20260720
                       ショート_消込漏れ_20260720
                       口座突合_点検結果_20260715
                       GH振込13件_再判定_20260715
                       仮払_売掛_点検リスト_20260714

     C-要確認 … チェックなし。あとで根拠として要るかもしれないもの。
                 引継ぎ資料_売掛金クリーンアップ_20260713.md
                 売掛計上_日中一時_計上漏れ_MF取込用
                 残作業リスト_20260714_1433版
                 …など。中身を見て、要らなければ手でチェックを付ける。

     C-常用 … チェックなし。日常的に使っているマスタの可能性。
               飲料納価・売価一覧 / 日計・月間収支報告 /
               請求額・入金額確認表 / 手数料明細送付先一覧 など。
               ここにチェックを付けないよう注意。

  4. チェックを直したら 関数「STEP2_チェックした行をゴミ箱へ」を実行

  ※ ゴミ箱への移動です。30日以内なら「STEP3_ゴミ箱から戻す」で戻せます。


■ 設定（作業CONFIG）
  対象範囲               'ルート直下' … マイドライブ直下だけ（既定・安全）
                         '全体'       … フォルダの中も全部
  何日より前を対象にするか  14 … 直近14日以内にさわったものは自動チェックしない
                              0 にすると新しいものも対象になる
  自分の所有ファイルのみ   true … 他人から共有されたファイルは触らない

  ・判定に使う言葉は「作業ワード」「保護ワード」の配列で調整できます。
    残したい種類のファイルがあれば、その言葉を 保護ワード に足してください。


■ 注意（会計まわり）
  ・MF取込用のファイルは、実際に何を仕訳として取り込んだかの記録になります。
    決算や税務調査で聞かれる可能性があるため、既定では自動チェックしていません。
  ・引継ぎ資料も同様に自動チェックの対象外です。
  ・売上伝票そのもの（xlsx）は帳簿書類で7年保存が要るので、
    このツールでは触りません（売上伝票.gs 側で重複分のみ整理）。
